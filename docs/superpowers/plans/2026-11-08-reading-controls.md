# 記事一覧と既読操作の改善 実装計画

**Goal:** 一覧から既読を取り消し、多くの記事を見渡し、元記事へ1操作で移動できるようにする。
**Spec:** ユーザー指定の3点。既読を未読へ戻す／表示件数を増やせるコンパクト表示／一覧から元記事を直接開く。
**Architecture:** 既存のReaderState.readと同期処理を利用。表示形式は既存の画面内状態を3種類へ拡張し、保存形式・API・認証は変更しない。
**Files:** app/page.tsx、app/globals.css、README.md。

## 実装
- [x] 各記事に既読/未読の切り替えを追加。詳細末尾の未読操作を主要アクションへ移す。
- [x] カード・リストにコンパクト表示を追加。PCでは見出しを1行にし、スマートフォンでは操作領域を確保する。
- [x] 各記事に元記事の通常のリンクを追加。新しいタブで開き、既読へ変更する。詳細表示は開かない。

## 検証と公開
- [x] ブラウザーで既読→未読、未読のみフィルター、再読み込み後の保持を確認。
- [x] 3表示で保存・既読操作・元記事リンクの挙動を確認。通常クリックと中クリックで詳細を開かず、元URLへ遷移することを確認。
- [x] デスクトップで行高短縮、スマートフォンで横はみ出しと操作領域を確認。
- [x] 既存101テスト・tsc・build・diff確認。今回の小規模UI変更には実装をなぞる自動テストを追加せず、実際のブラウザー操作で検証する。
- 公開は同じ本人限定Siteへソースをpushし、Sitesのデプロイ結果で成功を確認する。

## 検証記録
既存101テスト・tsc・build成功。PCで通常リスト173pxに対しコンパクト53px。320/390pxの各表示と、481pxのカード/コンパクトで横はみ出しを確認。独立レビューで挙がった481pxのカード操作欄の欠けを実画面で再現し、折り返しで修正後、表示中30記事のリンク欠け・footerはみ出しがともに0件になった。

未読のみの状態で、実RSSのTechCrunch記事への通常クリック・中クリックが新規タブで開き、対象行が既読化で除外され、詳細が開かないことも確認。未読への戻しは再読み込み後も保持され、ローカルD1への保存がHTTP 200で成功。保存ボタンの切り替え・詳細からの未読化も確認。UI検証はローカル環境で行い、本番ユーザーのライブラリには書き込んでいない。
