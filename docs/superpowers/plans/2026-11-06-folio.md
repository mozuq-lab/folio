# Folio 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** 実RSSを購読し好みに応じて記事をランク付けできる日本語RSSリーダー。
**Architecture:** Vinextのserver APIでRSS/Atomを取得し、React clientで閲覧と個人化を行う。個人データはlocalStorageで保持。
**Tech Stack:** React, TypeScript, Vinext, fast-xml-parser, lucide-react, Node test runner。
**Spec:** docs/superpowers/specs/2026-11-06-folio-design.md

## Global Constraints
- 日本語UI。機密値をclientに含めない。実際の生成AI利用を偽らない。
- lib/types.tsを共通interfaceとし、独立ファイルを並行実装。

## Review Focus
- malformed RSS/Atom、HTML、危険URLはparser/APIで検証。
- 古い記事や同点は安定した順位と有限スコア。
- localStorage破損時に初期値へ復帰。
- 全フィード取得失敗時に記事を消さない。
- 保存記事はRSS更新後も維持。
