# Folio RSSリーダー設計

ユーザーの依頼: FeedlyのようなRSSリーダーに、おすすめ記事の提案・おすすめ度ランキング・好みの反映を加える。

採用方針（実装側の判断）: Vinext / React / TypeScriptで、RSS取得はserver API、個人データはブラウザー保存とする。APIキーなしで動くcontent-based推薦を基本に、興味・記事への反応・新しさ・多様性からスコアと理由を算出する。外部生成AIを実際に接続しない限り、生成AIを使っていると表示しない。

比較した方法: 静的デモはRSS取得の制約が大きい。フルDB/アカウント実装は初期要件には過大。server API + browser persistenceなら実RSSと個人化を小さい構成で実現できる。

画面: 淡い白のsidebar、緑のアクセント、上部の検索、日付と挨拶、おすすめ一覧、右側の興味プロフィール。記事カードには画像、ソース、推薦スコア、タグ、保存操作。記事drawerに概要と元記事リンク、興味あり/なし。

操作: RSS追加/削除、手動更新、全文検索、カテゴリ/ソース/未読絞込み、新着/おすすめ切替、card/list切替、保存/既読、興味の編集、データexport。サンプル記事はサンプルと明示し、取得成功時は実フィードに差し替える。全失敗時はエラーを表示し既存記事を保持する。

品質: RSS/Atom対応、XMLからのtext抽出、危険URLの拒否、redirect再検証、timeout/size制限、本文HTMLは描画しない。empty/error/loading状態、keyboard/レスポンシブ対応。Sitesで本人限定公開。
